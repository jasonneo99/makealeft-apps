MemoryPilot Pro 1.0.

Production build 7 · released August 28, 2026.

What is included

  • Automatic daily update checks plus a manual Check for Updates command.
  • Checksum verification before a notarized update installer is opened.
  • Live CPU, native memory-pressure, storage, process-impact, and history dashboards.
  • Reviewed process controls and eligible-cache cleanup.
  • Disk Autopilot with confirmation, earned-trust controls, immutable 500-file and 2 GB per-run caps, emergency stop, and Trash-based recovery.
  • Remote Mac monitoring and explicitly authorized SSH remediation workflows.
  • Production license activation, two-Mac device management, recovery, offline grace, and automatic refund revocation.

Requirements

macOS 14 or later. Some optional disk and remote-management capabilities require permissions that macOS presents to the user. MemoryPilot does not bypass those controls.

Update behavior

Pro checks the Make a Left release feed once daily. Updates remain user-approved: MemoryPilot downloads the DMG, verifies its published SHA-256 checksum, and opens it for installation. Core monitoring remains available if activation is unavailable, but Pro-only actions require a valid license after the trial and offline grace periods.
