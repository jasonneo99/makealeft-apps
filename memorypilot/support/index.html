SUPPORT

How can we help?

MemoryPilot begins monitoring CPU, memory pressure, disk capacity, and process impact when the app opens. The Store edition requires no account. Pro uses a purchase email and license key for activation.

Storage analysis

Choose a folder through the standard macOS folder picker. MemoryPilot analyzes only that selected location. You can review suggested backup or removal actions before making changes.

AI features

AI Advisor and Chat are optional. Add your own OpenAI API key in Settings to enable them. The key is stored in macOS Keychain. Review the on-screen disclosure before sending diagnostics.

Troubleshooting

  • Refresh the dashboard if a recent system change is not yet visible.
  • Confirm that the selected folder is still available if storage analysis cannot run.
  • Remove and re-add the OpenAI API key if AI requests report an authentication error.
  • Core monitoring and storage analysis remain available without AI.

MemoryPilot Pro license

Your license is sent separately from the Stripe receipt by licenses@mail.makealeft.app. In MemoryPilot Pro, open Settings and enter the key under Licensing. A license supports two active Macs. If the message does not arrive, check Spam or Promotions, then email support from the same address used at checkout. Refunds and disputes disable the related license automatically.

Install Pro

Download MemoryPilot Pro 1.0. Open the DMG, drag MemoryPilot Pro to Applications, and launch it normally. The app and disk image are Developer ID signed, notarized, and stapled by Apple.
