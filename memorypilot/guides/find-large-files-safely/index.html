Storage cleanup

How to find large files safely

A useful storage scan should surface files large enough to matter—not just rank a few small folders—and give you context before deletion.

Start with categories, then files

Compare Documents, Downloads, media, developer data, app containers, and caches. Drill into the largest category and sort individual items by size; folder totals alone can hide the real offender.

Review four things before removal

  • Ownership: do you recognize the file and the app that created it?
  • Age: is it an active project or an old export?
  • Recoverability: is it backed up or downloadable again?
  • Location: is it personal data, an app container, or a protected system item?

Back up before you delete

Move irreplaceable work to a verified backup. For uncertain items, move them to Trash first and test the related app before emptying it.

Good first targets: duplicate installers, completed video exports, old archives, abandoned virtual-machine images, and downloads you can obtain again. Avoid deleting inside Library or System unless you know the owner and consequence.

Keep enough working room

Very low free space can slow updates, swap, caches, and large-file operations. MemoryPilot ranks storage offenders and separates reviewable personal files from more sensitive locations.
